# RTMC64 のソフトウェアパッケージの置き場所

このフォルダには、RTMC64 のソフトウェアパッケージ（通信ライブラリの本体、ヘッダーファイルなど）を置きます。
設計の検討で、構造体や定数の正確な定義を確かめるために使います。

> **このフォルダの中身は Git に入れません。**
> ソフトウェアパッケージとライブラリ本体は、製品を購入した人だけが入手できるものです。
> Git で共有するのは、この README だけです（[.gitignore](../../../../.gitignore) の「製品のソフトウェアパッケージ」）。
> マニュアル（[source/](../source/)）は、ホームページでユーザー登録すれば読めるので、Git に入れています。

## クローンしたあとにやること

1. ソフトウェアパッケージを入手します。入手先は **未整備** です（分かる方は追記してください）。
2. パッケージを、手を加えずにこのフォルダの下へ置きます。フォルダ名は `<機種>_<パッケージの版>` にします。
   ```
   docs/03_reference/rtmc64/sdk/
   ├─ README.md            ← この資料（Git で共有）
   └─ RTMC64-EC_<版>/      ← パッケージの中身（Git に入れない）
   ```
3. `git status` で、パッケージのファイルが表示されないことを確かめます。

## 注意

- パッケージの中身は書き換えません。Claude Code は、権限設定でこのフォルダの下の書き換えを拒否されています（[.claude/README.md](../../../../.claude/README.md)）。
- パッケージに入っているサンプルプログラムは、ビルドも実行もしません。軸を動かすものがあるかもしれないためです（[constitution](../../../../.specify/memory/constitution.md) 原則 I）。
- ヘッダーの中身を、Git に入るファイル（このフォルダの外の資料など）にそのまま写さないでください。設計に必要な点は、要点と、どのファイルのどこにあるかを書くにとどめます。
